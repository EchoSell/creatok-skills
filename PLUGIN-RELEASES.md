# CreatOK Plugins

[Download CreatOK Plugins](plugins/creatok-plugins.zip). This is the Codex plugin package, intended as a starting point for a general plugin compatible with Codex and other agent hosts. Hermes and Claude Code compatibility and installation are not yet verified; host-specific support for the plugin manifest, Skills, MCP and OAuth must be tested before claiming compatibility.

This development snapshot was built from local connector-packages branch `codex/creatok-skill-conflict-notice`, commit `981e9aa8ab7390a7cef407d78b0125baa19ef951`. It is not a published release; this source commit must be published before distributing the snapshot. Verify it with `shasum -a 256 -c PLUGIN-SHA256SUMS` from the repository root. The connector-packages repository is the source of truth.

Doubao and WorkBuddy distribution is through their respective official marketplaces. Their marketplace installation and connection flows still need end-to-end verification.

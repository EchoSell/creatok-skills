# CreatOK Plugins

[Download CreatOK Plugins](plugins/codex/plugin/creatok-plugins.zip). This is the Codex plugin package, intended as a starting point for a general plugin compatible with Codex and other agent hosts. Hermes and Claude Code compatibility and installation are not yet verified; host-specific support for the plugin manifest, Skills, MCP and OAuth must be tested before claiming compatibility.

This snapshot was built from connector-packages main commit [`85fdaf384aea9f45b865ea5ca374de5acf6c50c2`](https://github.com/EchoSell/creatok-connector-packages/commit/85fdaf384aea9f45b865ea5ca374de5acf6c50c2). Verify it with `shasum -a 256 -c PLUGIN-SHA256SUMS` from the repository root. The connector-packages repository is the source of truth.

Doubao and WorkBuddy distribution is through their respective official marketplaces. Their marketplace installation and connection flows still need end-to-end verification.
